# MultiVoice — свой мессенджер с голосовыми каналами

Десктоп-аналог Discord: Electron + React (клиент) и Node + WebSocket + SQLite (сервер),
с голосовыми каналами на WebRTC (P2P между участниками).

## Структура

```
multitool-voice/
├─ server/            Node + ws + node:sqlite (WebSocket API + WebRTC-сигнализация)
│  └─ src/
│     ├─ index.js     HTTP + точка входа
│     ├─ chat.js      WebSocket-обработчик (аутентификация, каналы, сообщения, голос)
│     └─ db.js        SQLite-слой (использует встроенный node:sqlite)
├─ app/               Electron + React (Vite)
│  └─ src/            React-клиент (UI + WebRTC)
└─ test/smoke.mjs     интеграционный тест (11 проверок)
```

## Требования

- Node.js >= 22 (используется встроенный `node:sqlite`, Node 24 рекомендован)
- npm

## Запуск

```bash
# 1. Установить зависимости (из корня multitool-voice)
npm install

# 2. Собрать и запустить сервер (в отдельном терминале)
npm run server        # поднимает ws://localhost:3001/ws

# 3. Собрать и запустить клиент (в другом терминале)
npm run app           # npm run build (Vite) + electron .
```

Откройте приложение в двух окнах (или на двух машинах в одной сети,
поменяв адрес сервера в `app/src/socket.js`) и зарегистрируйте двух пользователей.

## Что умеет

- Регистрация / вход (пароли хэшируются scrypt, токены в памяти сервера)
- Серверы (guilds), создание, вступление, выход
- Категории и каналы: текстовые (`#`) и голосовые (`🔊`)
- Текстовый чат в реальном времени (все участники сервера видят сообщения)
- Голосовые каналы на WebRTC (getUserMedia + RTCPeerConnection P2P, сигнализация через сервер)
- Прямые сообщения (ЛС) между пользователями
- Тёмная тема в стиле Discord

## Тест

```bash
npm run build --workspace server   # нужна свежая сборка
node test/smoke.mjs                # поднимает временный сервер, гоняет 11 сценариев
```

## Примечания

- Данные хранятся в `server/data/db.sqlite` (WAL). Для изолированного запуска
  задайте `APP_DATA_DIR=<путь>`.
- Голос работает P2P: для соединения между разными машинами нужны подходящие
  STUN (по умолчанию используются публичные Google STUN, указаны в socket.js).
- В Electron голосовые каналы поддерживаются: Chromium рендерит WebRTC без проблем.
